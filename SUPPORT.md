# Support

This document explains where to direct different kinds of questions and requests. Using the appropriate channel helps maintainers respond promptly and keeps the public record useful to others.

| Need | Channel |
| :--- | :--- |
| A question about using or contributing to the Project | GitHub Discussions, Q&A category |
| A proposal for new research or a research area | The Research Proposal issue template |
| A defect or enhancement in tooling or automation | The Tooling issue template |
| A change to governance, process, or the Charter | A [Consortium Proposal](proposals/README.md) |
| A security vulnerability | Private reporting, as described in [`SECURITY.md`](SECURITY.md) |
| A Code of Conduct concern | Private reporting, as described in [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) |

The Project is maintained by volunteers. Response times vary, and no service level is offered. Please read the existing documentation and search open and closed issues before asking.
